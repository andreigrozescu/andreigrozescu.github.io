Final Degree Project

Knowledge Graph-Based Container Security Monitoring

The widespread adoption of container technology such as Docker has transformed software deployment, but it has introduced significant challenges in terms of visibility and security. Managing containers poses critical issues for monitoring, traceability, and vulnerability control.

Current auditing tools typically focus on analyzing images statically and in isolation, without considering execution context or relationships between infrastructure components.

This project extends a container auditing tool by integrating dynamic monitoring and semantic Knowledge Graphs. It generates structured representations of containers, images, layers and dependencies.

The system enables SPARQL-based analysis for vulnerability detection, dependency tracking and forensic analysis in complex infrastructures.
