Final Degree Project

Knowledge Graph-Based Container Security Monitoring

The widespread adoption of container technology such as Docker has transformed software deployment, but it has introduced significant challenges in terms of visibility and security. Managing containers poses critical issues for monitoring, traceability, and vulnerability control.

Current auditing tools typically focus on analyzing images statically and in isolation, without considering the execution context or relationships between infrastructure components. This reduces operational visibility and makes real-time vulnerability assessment difficult.

This Final Degree Project extends the C2T tool by incorporating dynamic monitoring and semantic Knowledge Graphs. The system integrates data extraction, normalization, and unification from Docker containers, generating a graph that represents images, layers, packages, and running containers.

The solution enables advanced SPARQL queries to identify vulnerabilities, analyze dependencies, audit configurations, and trace the origin of failures. It was validated in a realistic environment and demonstrated scalability for large infrastructures.
